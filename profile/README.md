# SEMA

> SEMA keeps roof geometry and timber stairs on one Windows desk: open the carpentry project, check the wall module, and leave a shop note that matches the 3D.

## Four Beats

1. **Name the roof.** Give the SEMA carpentry project a short title before you touch geometry.
2. **Pin the live bays.** Keep current timber on SEMA timber and roof design and leave unused valleys aside.
3. **Read the modules.** Open SEMA stair and wall modules before you move a flight that already has a cut.
4. **Check the shop note.** Read the SEMA shop note before you archive a wall.
5. **Close the loop.** Clear finished modules so the next SEMA visit does not start with a search.
6. **Leave the 3D matching.** Keep the shop note aligned with the SEMA model on the desk.

## First Questions

**Does SEMA replace every other program?**
No. SEMA sits beside the cutter list, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate SEMA profile.

**Will SEMA feel heavy on an older laptop?**
No. SEMA is meant to stay readable during a normal carpentry session.

**What should a new user try first?**
One small SEMA stair module today, then the same roof design tomorrow.

**Do stair modules leave the roof model?**
No. SEMA stair and wall modules sit on the same SEMA carpentry project as the shop note.

**Is SEMA only for a finished roof?**
No. SEMA can hold a single wall module while the rest of the shop stays off the board.

## Who Sits Down at SEMA

- **Roof design** — geometry stays on SEMA timber and roof design.
- **Stair module** — flights stay with SEMA stair and wall modules.
- **Carpentry project** — the shop note stays on one SEMA model.
- **Cutter desk** — the 3D on the desk matches the SEMA shop note.
- **Client frame** — drafts and delivery files stay apart inside SEMA.
- **Shared desk** — each SEMA profile keeps its own pins.
- **Handoff** — the next person can read the SEMA shop note without a tour.

## Field Note

SEMA is easier to trust when the carpentry project stays smaller than the folder it came from. A named roof shows what is active, the module pins show what you will cut today, and the shop note tells the next person which stair changed.

The same loop fits a single flight, a gable wall, or a shop shared by two people. Open the last SEMA timber and roof design, finish one module, and leave fewer loose tickets than you found.

A cutter should not have to guess which 3D on the desk belongs to the shop note. Keep that pair together inside SEMA.

## One Real Pass

Pick a roof or stair that already has a name. Open it in SEMA, keep only those modules on the carpentry project, and finish one shop note you can see.
